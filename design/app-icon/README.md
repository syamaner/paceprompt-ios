# PacePrompt app icon exports

GitHub issue #9 selects the `2c-ceiling` family as the PacePrompt app icon.
The 1024 px export is installed unchanged as the single-size source in
`PacePrompt/Assets.xcassets/AppIcon.appiconset`. The 120 px and 180 px exports
are retained here unchanged as the issue's reference and legacy sizes; they are
not compiled into the app icon set.

No resizing, cropping, colour conversion, transparency change or corner
rounding was applied to any supplied export.
