Status: operator-accepted aggregate publication. This is a one-repetition host evaluation and a recorded human choice for a separate reviewed production change, not an automatic model selection or a device test.

- Run ID: `sol56-vs-sol6-20260922-01`.
- Production `issue130-r2` prompt, unchanged 79-case v3 held-out corpus, 30-case issue #130 reviewer acceptance corpus, strict schema, transport and deterministic scorer were hash-pinned before execution.
- Exact OpenRouter OpenAI routes: `openai/gpt-5.6-sol-20260709/openai` and `openai/gpt-6-sol-20260922/openai`; reasoning disabled, 6,144-token output ceiling, no fallback or automatic retry.
- One development warm-up and 109 scored attempts per model: all 220 scheduled calls completed. All 218 scored responses were schema-valid and classified as model-quality results. No rate-limit pause or not-started case occurred.
- The local evidence-integrity audit passed with no errors. Its `providerDecision` remains `requiresHumanRatification`; the scorer chose no automatic winner.
- The USD 26.00 hard limit was enforced. The provider-reported run cost, including warm-ups, was USD 1.8668044: USD 0.9342722 for GPT-5.6 Sol and USD 0.9325322 for GPT-6 Sol. These are observed route charges, not the USD 25.080060 conservative preflight bound.

The provider reported cached and cache-write token components; the byte-preserved local run evidence remains the authority for usage and charges. Neither model had a meaningful price advantage in this run.

## Unchanged gate interpretation

Neither model is decision-eligible under the unchanged scorer. Both pass schema validity and safety-refusal exactness. In the issue #130 stratum, `capabilityBoundaryExactness` is false for both because that corpus has no `knownCapabilityUnsupported` case; the inherited v3 gate treats an empty category as false. In the v3 stratum, both miss a category-attempt floor; GPT-5.6 Sol also misses a category-majority floor. No gate was relaxed or reinterpreted to select a winner.

This single pass favours GPT-6 Sol on strict exactness and host p95, with effectively equal observed cost. It does not establish repetition stability. After reviewing these results, the operator selected GPT-6 Sol for a separate reviewed production change. That is a human preference, not a scorer winner or a relaxation of the failed gates. GPT-5.6 Sol remains the production model; the implementation and any gate disposition require their own review. This publication changes no app configuration.
